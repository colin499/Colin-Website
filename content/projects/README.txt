Each project has its own folder in here, holding one .md file and the
project's photos and videos. Each project becomes a button on the left of
the projects page. In the .md file, write ![](photo.jpeg) on its own line
for each photo, and any text you want under it right below.
A folder called "not-shown" inside a project's folder is ignored, so you
can keep spare photos or videos there.
See "Add a project" in HOW-TO-EDIT.md.
